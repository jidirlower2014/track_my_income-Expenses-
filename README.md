# Hisaab Khata

Income/expense tracker, udhaar khata, bill generator aur WhatsApp reminders ek hi app mein.
Made by Ihsan - 03088052545

## Features
- Dashboard: total income, expenses, udhaar
- Income & expense tracker (categories ke sath)
- Customer khata: profile, balance, transaction history
- Kaam ki tafseel se bill (adaygi + baqaya), WhatsApp par bhejna, Print/PDF
- WhatsApp reminder (pre-written message, editable)
- Business logo, naam, contact number (app aur bill par)
- Mukhtalif themes
- Offline chalti hai, phone/desktop par install ho sakti hai (PWA)

Data aap ke browser mein (localStorage) mehfooz hota hai. Settings se backup lete rahein.

## GitHub Pages par chalana
1. GitHub par naya repository banayein (maslan `hisaab-khata`).
2. In sab files ko repository mein upload karein (`index.html`, `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`, `README.md`).
3. Repository ki **Settings -> Pages** mein jayein.
4. **Source: Deploy from a branch**, branch `main`, folder `/ (root)` chunein, Save karein.
5. 1-2 minute baad link milega: `https://<aap-ka-username>.github.io/hisaab-khata/`
6. Ye link Chrome mein kholein, phir menu se **Install app / Add to Home screen** dabayein.
